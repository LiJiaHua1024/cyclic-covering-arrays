# 环形约束覆盖数组的精确界、整数规划间隙与渐近极限理论

## 项目简介

本项目汇总并统一了二元、强度 2、指数 2（$\lambda=2$）、在环图 $C_n$ 上禁止相邻同时开启的约束覆盖数组的完整理论研究、机械化验证程序以及论文手稿。

---

## 核心定理总览

1. **[T1] 全域普适局部打分与统一下界（对所有 $n \ge 11$）**
   - 证明了对所有合法行，均有 $3P_3(x) + 2P_4(x) + P_5(x) \le n$。
   - 确立了对所有 $n \ge 11$ 的环拓扑，分数松弛与整数解满足：$LP(n) \ge 12, N(n) \ge 12$。
2. **[T2-T4] 小环精确最优值与整数规划间隙（$n = 13, 14, 15$）**
   - 证明了 $LP(13)=LP(14)=LP(15)=12$ 且 $N(13)=N(14)=N(15)=13$。
   - 在这三个连续整数上均存在严格的整数规划间隙 $G(n) = 1$。
   - $C_{13}$ 的不可行性证明即便允许行重复也依然成立。
3. **[T5] 分数松弛渐近极限收敛定理（最新突破）**
   - 严格证明了：
     $$\lim_{n \to \infty} LP(n) = 12$$
   - 且以指数级速度收敛：$12 \le LP(n) \le 12 + C\theta^n$（其中 $0 < \theta < 1$）。
   - 构造了记住两步历史间隙的 4 状态马尔可夫链，突破了距离 7 的概率瓶颈，使全距离二元状态概率均 $\ge 1/6$。
4. **[T6] 整数渐近发散与无穷间隙**
   - 整数规模 $N(n) = \Theta(\log n)$，与保持有界的分数松弛形成鲜明对比，整数规划间隙趋于无穷大：$G(n) = N(n) - LP(n) \to \infty$。
5. **[T7] $C_{17}$ 精确极值与下界闭环定理**
   - 严格证明了 $LP(17) = 12, N(17) = 13$，整数规划间隙 $G(17) = 1$。
   - 通过 51 位位并行 DFS 遍历 54,310 个节点，严格排除了 119 个等号行上的所有 12 行解（即使允许行重复依然不存解）。
6. **[T8] $C_{19}$ 精确极值与下界闭环定理**
   - 严格证明了 $LP(19) = 12, N(19) = 13$，整数规划间隙 $G(19) = 1$。
   - 通过 57 位/76 位位并行 DFS 遍历 726,693 个节点（~42 秒），严格排除了 209 个等号行上的所有 12 行解。
   - 确立连续五个小环 $N(13)=N(14)=N(15)=N(17)=N(19)=13$，证明使最优行数首次达到 14 行的最小奇数环长必须满足 $n^*_{\text{odd}} \ge 21$。
7. **[T9] 偶数环容量与连续平坦带定理（最新突破）**
   - 构造了 $C_{16}$（464 状态）与 $C_{18}$（594 状态）的显式 13 行解，证明对区间 $[13, 19]$ 内的所有 7 个连续整数均有 $N(n) \le 13$。
   - 确立全局跳跃阈值下界：$n^*_{\text{global}} \ge 20$。
8. **[T10] $C_{21}$ 显式 14 行上界与 13 行近解刚性排斥（最新突破）**
   - 构造了 $C_{21}$ 的 14 行显式覆盖阵列（819 个有效两列状态全部 $\ge 2$ 重覆盖），确立 $12 \le LP(21) \le N(21) \le 14$。
   - 发现仅缺 1 项 $((5, 15)=11)$ 的 13 行近解，经全部 24,476 个合法行在 40,826 个候选组合上的穷尽检查，证明该近解严格不存在任何 1 行或 2 行替换修补方案。

## 一键机械化验证

无需安装任何第三方库，使用 Python 标准库完成全量验证：


- `python verifiers/verify_c13.py`：独立复核 $C_{13}$ 整数间隙代数证书。
- `python verifiers/verify_c14.py`：独立复核 $C_{14}$ 模 7 同余矛盾证书。
- `python verifiers/verify_c15.py`：独立复核 $C_{15}$ 的 4823 个 $\mathbb{F}_2$ 秩证书与有理数见证。
